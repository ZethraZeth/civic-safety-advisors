# Civic Safety Advisors (Starter)

## Run locally
1. Install deps
   - `npm install`
2. Start dev server
   - `npm run dev`

## Notes
- The Juristic HTML template assets are copied into `public/assets/`.
- Template CSS is linked in `app/layout.tsx`.
- Tailwind is enabled and used for the home page + shared components.
